Quem é quem

Cliente

Agenda pelo WhatsApp

Qualquer número que não seja de um profissional cadastrado. No 1º contato a Sof pede nome e sobrenome.

Profissional

Opera a agenda

Número cadastrado em Profissionais (com ou sem DDI 55). A Sof abre o menu operacional — não o cardápio de cliente.

O telefone do profissional precisa estar certo. Se estiver errado, ele cai no fluxo de cliente.

Fluxo do cliente

Serviço → Profissional ou horário → Dia → Horário → Confirma

1º contato

Se o telefone ainda não é cliente, a Sof pede nome e sobrenome (mín. 2 palavras) antes do menu.

Marcar horário

  1. Escolhe o serviço (com preço).
  2. Escolhe um profissional que faz aquele serviço ou “Escolher horário” primeiro.
  3. Escolhe o dia: Hoje / Amanhã / Outra data (dd/mm).
  4. Escolhe o horário (até 5 opções do dia ou “Outro horário”).
  5. Se escolheu horário primeiro: quem está livre + opção “Deixa a Sof escolher”.
  6. Confirma (Sim / Não) → entra na agenda.

Se existir agendamento futuro, o menu também mostra Ver agendamentos e Cancelar horário (com confirmação Sim/Não).

Frase livre e áudio

Texto corrido

Ex.: “quero marcar um corte amanhã ao meio-dia” — a Sof tenta pular direto para a confirmação. Se não entender, volta ao menu guiado.

Áudio

Mensagens de voz são convertidas em texto (planos com esse recurso). Se falhar, a Sof pede para escrever ou usar os botões.

Fluxo do profissional

O profissional manda mensagem para o mesmo WhatsApp do salão, com o telefone cadastrado em Profissionais.

Novo agendamento pelo profissional

Serviço → Dia → Horário livre → Nome + telefone do cliente → Confirma

Evento / bloqueio

Título → Duração 30/60/90/120 → Dia → Horário → Confirma

Eventos ocupam a agenda (conflito), mas não entram no faturamento.

Extras úteis

Lembrete ao cliente

Em Conta (com WhatsApp conectado), configure a antecedência (1h, 2h, 24h…). A Sof avisa 1× por agendamento.

Pausar o bot

Conta: silencia para todos os clientes. Na aba Clientes: pausa só aquele cliente. Profissionais continuam no menu operacional.

Atendimentos (humano)

Pedido de atendente ou várias respostas “não entendi” abrem alerta no painel. Se alguém responder pelo WhatsApp Web/celular, o bot pausa 1h para aquele cliente.

Simulador

No painel: Agenda → botão Simulador WhatsApp (/simulador (telefone + mensagem). Use o telefone do profissional para testar o menu operacional.

Dicas para o salão

  • Cadastre o telefone do profissional exatamente como ele usa no WhatsApp
  • Vincule cada profissional aos serviços que ele realmente faz
  • Mantenha endereço e horário atualizados em Conta
  • Teste uma vez como cliente e uma vez como profissional no Simulador WhatsApp (/simulador)
  • Avise a equipe: o bot do salão também é a ferramenta deles no celular
